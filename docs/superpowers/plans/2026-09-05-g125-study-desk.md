## Rulings (binding)

- **R1 — counts, never charts.** The page draws spines and rows; no bars-per-source, no tiles, no age histogram. The book pile encodes *characters queued* on a log scale; the study list carries the *counts*. One number, one encoding.
- **R2 — `reading` on the Sleep page only.** `deriveSleepPageMood` returns `.reading` where it returned `.curious(count:)`; `deriveBookwormState` (menu bar) is byte-for-byte unchanged, and `.curious` keeps meaning inbox items there. `store.intakeInFlight` (set by the upload overlay while an upload/import runs) forces `.reading` ahead of happy/hungry but never ahead of sleeping/error/digesting.
- **R3 — the countdown is Stage 1.** `read_by_origin` ticks when Stage 1 finishes an episode (the only stage with a per-episode unit — `progress_pct`'s own rule). The study list shows `read / total` per source while `stage == 0` and a "filing…" state for stages 2-5; rows reach zero when Stage 5 marks episodes processed and the next `/sleep/episodes` fetch lands (the existing reconcile). The bubble names the stage honestly: stage 1 "Reading…", stage 5 "Filing everything away."
- **R4 — history is parsed server-side, bounded, cached.** `get_sleep_history(memory_path, limit=15)` reads `git log -n <limit * 3>` (the grep filter plus non-Sleep commits between cycles means a raw window larger than `limit`), parses bodies in Python, and returns at most `limit` entries; the body never crosses the wire (the M1 lesson at `git_service.py:876-888` stays honoured). Cached per `(memory_path, git_head, limit)` in a module dict, like `status._last_sleep_cache`. `files_changed` is now derived from the manifest lines (every `<path>:` prefix), no `diff-tree` — same shape, ~1 subprocess per request instead of N+1.
- **R5 — duration is joined, never guessed.** `duration_ms` comes only from a `sleep_run` ledger row whose `refs.commit` matches the commit (full-hash prefix match either way, ≥ 7 chars). Telemetry off, row missing, or `refs.commit is None` → `None`, and the app prints "—". Estimates stay deferred (G107).
- **R6 — schedule modes derive `enabled`.** `ScheduleConfig.mode` is the source of truth; `enabled` is `mode != "manual"`, always written on the wire for older readers. An old YAML (no `mode`) loads as `daily` if `enabled` else `manual`. An old client's `PUT {enabled,hour,minute}` (no `mode`) is accepted with the same derivation — `mode` is `Optional` on input, filled by a validator. `interval_hours` 1…168, default 6.
- **R7 — "after imports" means "the queue has settled".** No writer calls a hook. `register_job` for `after_import` installs an `IntervalTrigger(minutes=5)` probe `_run_after_intake_if_settled(settings)` that triggers `run(..., user_triggered=False)` iff idle, `unprocessed_count > 0`, and the NEWEST unprocessed episode's timestamp is ≥ `AFTER_IMPORT_SETTLE_MINUTES` (10) old. `next_run_at` for this mode = newest unprocessed + 10 min (or `None` with an empty queue). `sleep_debt` gains `newest_unprocessed_at` so the probe and `next_run_at` share one scan.
- **R8 — the bubble never reads the clock.** `sleepBubbleText`'s variant is `(count + stage) % variants.count`; the caller passes `debt`/`stage` it already has. Copy: ≤ 60 characters, first person, one sentence, no exclamation marks in `hungry`/`error`, counts and source *labels* only.
- **R9 — the pile is a pure layout.** `bookPileLayout` is deterministic; height `8 + 6·log2(1 + chars/2000)` clamped 8…40; `widthFraction = remaining / count` while running else 1; sort by chars desc, then origin; fold beyond `maxBooks` into one remainder spec (`origin: "+more"`, `count: N`). A `chars` of 0 still yields the 8 pt minimum (an episode with no body is still a book).
- **R10 — one Consolidate button.** It lives in the study list card's footer (was `SleepQueueCard`); the top-right Sleep/Upload pair leaves this page. `TopBarControls` keeps its defaults so Graph/Clusters are untouched.
- **R11 — every deleted view's pure logic survives with its tests.** `SleepQueueCard.loadState` → `StudyListCard.loadState`; `groupEpisodesByOrigin` / `parseEpisodeTimestamp` → `SleepQueueModel.swift`; `SleepQueueCardTests` → `StudyListCardTests` (same four cases + new ones). Nothing is dropped, only renamed.
- **R12 — history rows open on demand.** `SleepViewModel.loadDetail(commit)` fetches once and caches in `details[commit]`; a second click is a dictionary hit. Detail requests carry the same `loadToken` guard as `load()` so a bank switch mid-fetch never paints another bank's cycle.

_ENTITY_PATH_RE = re.compile(r"^entities/(?P<id>.+)\.md$")

@dataclass
class CycleManifest:
    entities: list[dict]
    files: list[str]
    episodes: list[str]
    inbox_changes: int
    authors: list[str]
    sessions: list[str]

def parse_cycle_body(subject: str, body: str) -> CycleManifest:
    """Read a Sleep-cycle commit body back into counts (G125 R4).

    The body is what ``sleep_cycle._finalize`` wrote: one ``<path>: <action>
    (source: <ep|n/a>, trigger: <t>[, sessions: …])`` line per file, then the
    trailer block. ``n/a`` is not an episode. Unknown lines are ignored so a
    legacy or hand-written commit degrades to zeros rather than an error.
    """
    entities: list[dict] = []
    files: list[str] = []
    episodes: list[str] = []
    seen_eps: set[str] = set()
    inbox_changes = 0
    engine: str | None = None
    for raw in body.splitlines():
        line = raw.strip()
        if line.startswith(f"{ENGINE_TRAILER}:"):
            engine = line.split(":", 1)[1].strip() or None
            continue
        m = _MANIFEST_LINE_RE.match(line)
        if not m:
            continue
        path = m.group("path").strip()
        files.append(path)
        fields = {}
        for part in m.group("rest").split(","):
            if ":" in part:
                k, v = part.split(":", 1)
                fields[k.strip()] = v.strip()
        source = fields.get("source")
        source = None if not source or source == "n/a" else source
        if path.startswith("inbox/"):
            inbox_changes += 1
        em = _ENTITY_PATH_RE.match(path)
        if em:
            entities.append({"id": em.group("id"), "action": m.group("action"),
                             "source_episode": source, "trigger": fields.get("trigger", "")})
            if source and source not in seen_eps:
                seen_eps.add(source)
                episodes.append(source)
    return CycleManifest(entities=entities, files=files, episodes=episodes, inbox_changes=inbox_changes,
                         authors=_parse_authors(body), sessions=_parse_sessions(body), engine=engine)


def _cycle_kind(subject: str) -> str | None:
    s = subject.lower()
    if s.startswith("sleep cycle"):
        return "decay" if s.rstrip().endswith("(decay)") else "sleep"
    if s.startswith("inbox resolution"):
        return "inbox"
    return None


def _entry_from(commit_hash: str, date: str, subject: str, body: str) -> SleepHistoryEntry:

    return SleepHistoryEntry(

        entities_updated=sum(1 for e in m.entities if e["action"] != "created"),
        episodes=len(m.episodes), sessions=len(m.sessions), authors=m.authors,

_history_cache: dict[tuple[str, str, int], list[SleepHistoryEntry]] = {}


async def get_sleep_history(memory_path: Path, limit: int = 15) -> list[SleepHistoryEntry]:
    """The last ``limit`` consolidations, newest first (G125 R4).

    One ``git log -n limit*3`` with bodies, parsed HERE — the body never
    leaves the process (the M1 lesson in the 2026-09-01 review: ``%b`` over
    the wire grew this endpoint to 378 KB for eight commits). Cached per
    ``(memory_path, HEAD, limit)`` so a Sleep page poll costs no subprocess
    until HEAD moves. Durations are joined from the ledger (R5).
    """
    from api.services import sleep_history, sync_service, telemetry

    limit = max(1, int(limit))
    key = (str(memory_path), sync_service.git_head(memory_path), limit)
    cached = _history_cache.get(key)
    if cached is None:
        sep, rec = "\x1f", "\x1e"
        try:
            output = await _run_git(
                memory_path, "log", f"-n{limit * HISTORY_LOG_MULTIPLIER}",
                f"--format=%H{sep}%ad{sep}%s{sep}%b{rec}", "--date=short",
            )
        except GitError:
            return []
        entries: list[SleepHistoryEntry] = []
        for record in output.split(rec):
            if not record.strip():
                continue
            fields = record.strip("\n").split(sep, 3)
            if len(fields) < 4 or _cycle_kind(fields[2].strip()) is None:
                continue
            entries.append(_entry_from(fields[0].strip(), fields[1].strip(), fields[2].strip(), fields[3]))
            if len(entries) >= limit:
                break
        # No `.clear()`: this is a multi-key cache — the SAME shape as
        # `status._last_sleep_cache` — keyed on `(memory_path, head, limit)`
        # (R4). Wiping the dict on every miss would make two different
        # `limit`s at the SAME head evict each other forever, contradicting
        # "cached per (memory_path, git_head, limit)" above. Unbounded
        # growth is accepted the same way `_last_sleep_cache` accepts it:
        # trivially small at personal scale (one entry per unique head this
        # process has ever seen `/sleep/history` called against).
        _history_cache[key] = entries
        cached = entries
    out = [e.model_copy() for e in cached]
    # Bound the telemetry join the same way the git side is bounded: only
    # scan months that could possibly contain one of THESE entries' commits,
    # never the whole machine-global ledger (the exact class of cost this
    # function's own docstring above warns against for `%b` — a call site
    # that grows with the SIZE of everything that ever happened, not with
    # what this request actually needs). Nothing to join → skip the read.
    if out:
        oldest = min(date.fromisoformat(e.date) for e in out)
        sleep_history.attach_durations(out, telemetry.read_events(start=oldest))
    return out

    if not re.fullmatch(r"[0-9a-f]{7,40}", commit or ""):

    var hour: Int
    var minute: Int
    var intervalHours: Int

    /// older reader, never this struct's own source of truth. A naive
    /// `Codable` synthesis would try to assign a decoded `enabled` straight
    /// into a stored property; there is none, so `init(from:)`/`encode(to:)`

    init(mode: String, hour: Int, minute: Int, intervalHours: Int = 6) {
        self.mode = mode; self.hour = hour; self.minute = minute; self.intervalHours = intervalHours

func bookPileLayout(_ buckets: [OriginVolume], maxBooks: Int = 8) -> [BookSpec] {
    let sorted = buckets.sorted { $0.chars != $1.chars ? $0.chars > $1.chars : $0.origin < $1.origin }
    func height(_ chars: Int) -> CGFloat {
        let h = 8 + 6 * log2(1 + Double(max(0, chars)) / 2000)

    }
    var out = sorted.prefix(maxBooks).map { b in
        BookSpec(origin: b.origin, count: b.count, height: height(b.chars),
                 widthFraction: b.count > 0 ? min(1, max(0, Double(b.remaining) / Double(b.count))) : 1,
                 isRemainder: false)
    }

        out.append(BookSpec(origin: "+more", count: rest.reduce(0) { $0 + $1.count },
