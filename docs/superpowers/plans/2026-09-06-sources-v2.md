# Sources v2 (Track S) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Sources page stops presenting eleven near-identical cards with one green dot meaning
four different things. Every card becomes the same five bands — mark · brand name · **one status
verb that names the actual state** · a 14-day capture sparkline beside the lifetime total · four
week-dots beside a delta — on a fixed-height tile in one shared, zoom-aware column grid. Every
number in the window comes from one locale-correct formatter, pinned by a source lint, and the
backend stops shipping pre-formatted numbers inside `detail`. Contributors collapses from a wall of
expanding rows into one chip strip over a labelled stacked share-of-entities bar, with real provider
marks and no "?" for buckets the app can name. `+ Add a source` exists in the header at all times.

**Architecture:** Every decision on the page is a **pure function with a table test** — liveness,
display name, column count, delta text, share segments, the channel detail line — and the views are
thin renderers over them. No new endpoint, no new ETag component, no new Store domain. Track A's
`SourceOverview.activity` field and its `sparklinePoints`/`weekDots` helpers and Track L's
`OriginMark` / `ContributorIdentity` are **consumed, never re-implemented**. The one backend change
is additive: two scalar fields on `SourceChannel` so the number leaves `detail` and gets formatted
client-side.

**Tech Stack:** SwiftUI + XCTest (`app/CicadaApp`), Python 3 / FastAPI / Pydantic (`api/`), markdown
+ git bank.

**Spec:** `docs/superpowers/specs/2026-09-05-round2-study-room-marks-video-design.md` § *Track S —
Sources v2*, rulings **R-S1 … R-S7** (binding). Critique: a session scratchpad that is **not committed** — there is no `phase1/` directory in
this repo, so do not go looking for one. Its defect ids (A1–A5, B1–B2, C1–C4, D1–D5, E1–E4,
F1–F4) are cited per task and **every one of them is defined inline** in *What the code actually
does today* below; that section is the citable source. Backlog rows
**G124** (the Sources page), **G126** (standing vs one-shot), **G129** (the browser status light),
**G130** (`CicadaTheme.scaled` / the font lint this plan's count lint is modelled on), **G124 R2/R3**
(a row only with evidence; entity credit is `source_episodes` only). Standing rulings: the
2026-09-03 G124 ruling (**no prices, no tokens anywhere in the app**), ETag ship-together, privacy in
docs, portability.

## Rulings (binding)

The spec's **R-S1 … R-S7** hold as written. Everything below is a decision this plan takes where the
brief left a choice, with the reason, so no task re-opens it.

**One reconciliation first, so nobody "corrects" it back.** R-S4's example list says `unknown` →
"Before provenance". That name belongs to the **contributor** bucket (a legacy untrailered commit,
R-S6's half of the spec) and lands in R-S13. The Sources page's two `unknown` buckets are different
facts and get their own names: `origin:unknown` is *an episode with no `origin:` stamp* →
**"Unattributed"**, and `harness:unknown` is *an agent conversation whose harness never identified
itself* → **"Other agents"** (already `HARNESS_LABELS`' own word). Three buckets, three names, no
"?" — which is what R-S4 actually asks for.

- **R-S8 — one activity window implementation.** The brief's `SourceActivity.window(_:days:today:)`
  **already exists** as Track A's module-global `sparklinePoints(activity:days:today:)`
  (`Views/Sleep/MemorySourcesCard.swift:44`), with `weekDots` beside it and eight tests. Sources v2
  **calls those two functions directly** and adds no alias, no wrapper and no second name. A second
  spelling of the same window is exactly the drift the "one implementation" instruction forbids, and
  a `typealias` would make two names greppable for one behaviour.
- **R-S9 — the header's `+ Add a source` presents `AddSourceSheet` in place.** Not
  `AppRouter.routeToFeedAddSource`: that method takes a **non-optional** `AddSourceTile` and its
  whole purpose is staging one specific tile for the Feed. "Add a source" from this page means the
  catalog root (`initialTile: nil`), and bouncing the person to another tab to show a sheet that
  works fine here is a worse answer than presenting it. `AddSourceSheet` owns its own state and
  `@Environment(Store.self)`; two presenters of it is not a conflict. **The empty state keeps the
  affordance it has** (`SettingsSectionLink(.integrations)`) — R-S7's fix is that the page never
  *loses* a way in, not that both ways must be identical.
- **R-S10 — `isRefreshing` is deleted, not rendered.** C4 offers "use or delete". A 1 pt line that
  blinks under the section headers on every SSE version bump is motion nobody asked for, and the
  never-blank rule already means the grid shows last-known-good throughout. The parameter and its
  call-site argument go.
- **R-S11 — the status band is the light's home; the plain dot is retired.** Where a
  `BrowserWatchState` exists the card keeps `BrowserStatusLight(compact: true)` byte-for-byte
  (R-D6, `.blocked`'s `FullDiskAccessHint` unchanged on the detail page); where none exists the dot
  is tinted by `SourceLiveness`'s own tone, never by `source.connected`. `connected` means "has ever
  fed memory" (`source_overview.py:274-277`) and that is not a status — it is the reason the row
  exists at all (G124 R2).
- **R-S12 — no per-section liveness caption.** The critique sketches `3 live · 1 imported once`
  beside each section header. Every card in the section already prints its own verb; a roll-up would
  be a second encoding of the same fact, eighteen points away — the same rule G125 R1 draws for the
  book pile. Section headers keep their existing text.
- **R-S13 — `ContributorIdentity.displayName` learns the two buckets it was missing.** `user` →
  `Copy.you` ("You"), `unknown` → "Before provenance"; the model id stays its own honest id (Track
  L's reason is unchanged). `ContributorIdentityTests.swift:13`'s `== "user"` assertion is
  **updated, not worked around** — it pinned the raw id only because Track L had no reason to change
  it, and a second `stripName(...)` would let the strip and the drill-down disagree about who wrote
  the bank.
- **R-S14 — the strip reuses `ContributorAvatar`, and the drill-down moves without changing.**
  `ContributorAvatar` drops `private` (nothing else about it changes — it already draws the bookworm
  sprite for `system`, real provider marks for known providers, and initials otherwise). The
  drill-down body + its four `@State` caches + its two loaders move **verbatim** out of
  `ContributorRow` into an internal `ContributorDrillDown` view, so a chip's sheet and the old row
  render the identical thing from one definition.
- **R-S15 — a chip opens a sheet, not a route.** `SourcesRoute` (`SourcesPageView.swift:6-9`) is the
  *source-card* route and `SourceDetailView` binds ⌘[ to its Back button; a second case would make
  ⌘[ ambiguous and push the drill-down's 53-week calendar into the page's own scroll — E4's
  complaint. A sheet keeps the page one screen tall, which is the whole point of R-S6.
- **R-S16 — the number leaves `detail` behind two additive scalars.** `SourceChannel` gains
  `count_noun: Optional[str] = None` (the **singular** noun; the client pluralises with `+ "s"` —
  every noun in the registry, adapters included, is regular, and a backend test pins that) and
  `count_is_delta: bool = False` (true only for a connector's "items pulled THIS run", which
  `_connector_channel` documents at `:150-153` is not a total). `Optional[...]`, not `str | None`,
  to match every other field on that model (`schemas.py:1782-1788`). `CamelModel` puts them on the
  wire as `countNoun` / `countIsDelta`. `detail` keeps only its non-numeric clauses; one pure Swift
  composer, `ChannelDetailLine.text(_:locale:)`, puts them back together.
  A branch that must not show a count (a failed or skipped poll) simply sets `count_noun: None`, so
  "0 pins · Last sync failed" is unrepresentable rather than merely unlikely.

  **The composer, exactly** (or `ChannelDetailLineTests`' delta case is unreachable): the count
  phrase is `"\(UsageFormat.count(count, locale:)) \(noun)"` pluralised with `+ "s"` when
  `count != 1`, prefixed with `+` and **suffixed with `" this sync"` when `countIsDelta`** — the
  words `_connector_channel:150-153` currently bakes in. Phrase and `detail` are then joined by
  `" · "`, either alone when the other is absent, and the whole thing is `nil` when both are. So
  `count: 7, noun: "pin", isDelta: true, detail: "synced 2026-08-04"` → `"+7 pins this sync ·
  synced 2026-08-04"`, which is byte-identical to what the server prints today.
- **R-S17 — `UsageFormat.count` gains a locale parameter and changes its default.**
  `Locale.autoupdatingCurrent`, defaulted, with an explicit parameter so
  `count(1927, locale: es_ES) == "1.927"` and `count(1927, locale: en_US) == "1,927"` are both
  assertable. `usesGroupingSeparator = true` stays — it was there because `en_US_POSIX` does not
  group by default (`UsageFormat.swift:13-15`), and setting it explicitly is harmless for a real
  locale.
- **R-S18 — the count lint has a named scope and a documented escape hatch.** It walks
  `Views/Sources/`, `Views/Contributors/`, `Models/SourceOverview.swift` and
  `Models/IntegrationCategory.swift`; a line containing both `Text("` and `\(` must contain
  `UsageFormat.` **or** a trailing `// count-lint:ok — <reason>`. A whole-tree lint would drown in
  legitimate label interpolations and get disabled; a needle that tries to tell an `Int` from a
  `String` by name is a guess. This is the durable half of B1 — a behavior test cannot see a literal
  in a diff (`FontLiteralLintTests`' own reasoning).
- **R-S19 — two nouns, and the card's headline is a pair, not a string.** `SourceOverview.headline`
  returns `(count: Int, noun: String)?` so the tile can set the number and its unit in different
  fonts, and `countLines` (accessibility label, detail page) keeps its existing sentence shape. The
  total is **items / conversations / captures / subscriptions** per kind; the sparkline and delta are
  always **captured** (R-S3). A5 is fixed inside `countLines`' harness case rather than by letting it
  fall through to `default:` — "1 capture (no session recorded)" under a CHAT & AGENTS header, never
  a silent change of unit.

```swift
import SwiftUI

/// What a source is actually *doing* — R-S2, and the fix for the page's single
/// biggest legibility failure (critique D1).
///
/// Before this, the card painted `source.connected ? success : tertiary`, and
/// `build_overview` sets `connected = episodes > 0` for any row with no channel
/// (`api/services/source_overview.py:274-277`). So a live-watched Chrome, a
/// nightly-polled RSS feed, a hook-captured Claude Code session and a Claude
/// export imported once in July all showed the identical green dot. The dot's
/// real meaning was "has ever fed memory" — which is why the row EXISTS
/// (G124 R2), not what it is doing now.
///
/// Every input is already on the wire, so this needs **no backend field**:
/// `actions == ["import"]` is one-shot (`channel_registry._origin_channel:189`),
/// `poll` is the nightly connector poll, `sync` with no watch is on-demand,
/// `harness != nil` is hook capture (G105), a `BrowserWatchState` refines a
/// browser (G129), and `lastError` outranks all of it.
struct SourceLiveness: Equatable {
    enum State: String, CaseIterable {
        case watching, syncing, behind, blocked, failed
        case captured, pollsNightly, syncsOnDemand, imported
    }

    /// How the card tints its dot and its sparkline. Deliberately four tones,
    /// not a per-state colour: the verb carries the meaning, the tone carries
    /// only "fine / act / broken / dormant".
    enum Tone: Equatable { case live, warning, danger, dormant }

    let state: State
    /// The error's first clause, for `.failed` and `.blocked` only (D2 — a card
    /// with room for "506 items" has room for "Can't read"). The full text
    /// stays in the tooltip, exactly where it already was.
    let detail: String?

    /// The card's one status line. `.failed` folds its clause in; every other
    /// state is a fixed phrase, so two states can never print the same words
    /// (asserted).
    var verb: String {
        switch state {
        case .watching: "Watching"
        case .syncing: "Syncing…"
        case .behind: "Behind — sync now"
        case .blocked: detail.map { "Can't read — \($0)" } ?? "Can't read"
        case .failed: detail.map { "Sync failed — \($0)" } ?? "Sync failed"
        case .captured: "Captured by hook"
        case .pollsNightly: "Polls nightly"
        case .syncsOnDemand: "Syncs when you ask"
        case .imported: "Imported once"
        }
    }

    var tone: Tone {
        switch state {
        case .watching, .syncing, .captured, .pollsNightly: .live
        case .behind: .warning
        case .blocked, .failed: .danger
        case .syncsOnDemand, .imported: .dormant
        }
    }

    var isLive: Bool { tone == .live }

    /// Precedence, highest first — a broken source says so before anything
    /// else, and `.blocked` stays distinct from `.failed` because it is the one
    /// failure with something the person can do (`BrowserWatchState`'s own
    /// reason, `Services/BrowserWatch.swift:62-64`).
    static func of(row: SourceOverview, channel: SourceChannel?, watch: BrowserWatchState?) -> SourceLiveness {
        let clause = firstClause(of: row.lastError)
        if watch == .blocked { return .init(state: .blocked, detail: clause) }
        if watch == .failed || clause != nil { return .init(state: .failed, detail: clause) }
        if watch == .syncing { return .init(state: .syncing, detail: nil) }
        if watch == .stale { return .init(state: .behind, detail: nil) }
        if watch == .watching { return .init(state: .watching, detail: nil) }
        // `harness` is set only for the `harness:<name>` family — hook capture.
        // A chat export is `kind: .harness` with `harness == nil`, and lands on
        // `.imported` below, which is exactly the standing-vs-one-shot line
        // G126 draws and the old page never showed (critique F3).
        if row.harness != nil { return .init(state: .captured, detail: nil) }
        let actions = Set(channel?.actions ?? row.actions)
        if actions.contains("poll") { return .init(state: .pollsNightly, detail: nil) }
        if actions.contains("sync") { return .init(state: .syncsOnDemand, detail: nil) }
        return .init(state: .imported, detail: nil)
    }

    /// A card line, not a log line: the first clause of the error, cut on the
    /// first sentence or separator boundary and capped. The whole message stays
    /// in `.help()`.
    static let maxClauseLength = 42
    static func firstClause(of error: String?) -> String? {
        guard var text = error?.trimmingCharacters(in: .whitespacesAndNewlines), !text.isEmpty else { return nil }
        for separator in [" · ", ". ", "\n", ": "] {
            if let range = text.range(of: separator) { text = String(text[..<range.lowerBound]) }
        }
        text = text.trimmingCharacters(in: CharacterSet(charactersIn: " .·:")).trimmingCharacters(in: .whitespaces)
        guard !text.isEmpty else { return nil }
        if text.count > maxClauseLength { text = String(text.prefix(maxClauseLength - 1)) + "…" }
        return text
    }
}
```

1. Strip the `harness:` / `origin:` prefix; ask `OriginIconography.label(for:)` first (it already

export", "Safari tabs", "Saved links", "Other agents") and a fallback that reads differently from
the table is exactly the drift this type exists to remove. So `origin:rss-mirror` → "RSS mirror"

```swift
/// R-S1 — ONE column count for every section, derived once from the container
/// width in scaled units.
///
/// Two defects in one line. `.adaptive(minimum: 220, maximum: 320)` hardcoded
/// raw points while every font and spacing token inside the card goes through
/// `CicadaTheme.scaled` (C2), so at ⌘+ the text grew 40 % and the column did
/// not; and `.adaptive` + `.leading` left a card-shaped hole at the end of any
/// section whose row was short (C3). A fixed count fixes both, and it changes
/// in one place when the window resizes OR `uiScale` moves.
enum SourceGridColumns {
    /// The width one card wants before the grid adds a column. 260 pt at
    /// `uiScale == 1.0`, scaled with the chrome.
    static let unit: CGFloat = 260
    static func count(width: CGFloat, scale: CGFloat) -> Int {
        let per = unit * max(scale, 0.1)
        return max(2, min(4, Int((width / per).rounded(.down))))
    }
}
```

```swift
/// R-S3 — the delta is what makes the sparkline honest. The big number is a
/// LIFETIME total in the row's own unit (items / conversations / captures); the
/// line and this sentence are **captures** in the last 14 days. One noun for
/// both would let a browser's 506 bookmarks read as 506 recent captures.
enum SourceDeltaText {
    /// `locale` is a parameter for the same reason `UsageFormat.count`'s is
    /// (R-S17): the month name and the grouped number are both locale-bound, so
    /// a default of `.autoupdatingCurrent` is what the reader sees and an
    /// explicit argument is what a test can assert on any host. Without it this
    /// sentence is green on an `en` machine and red everywhere else.
    static func text(points: [Int], lastActivity: Date?, today: Date,
                     locale: Locale = .autoupdatingCurrent) -> String {
        let sum = points.reduce(0, +)
        // `points.count` is the window — never a second constant — so the
        // sentence and the line above it can never disagree about how many days
        // they cover.
        if sum > 0 {
            return "+\(UsageFormat.count(sum, locale: locale)) captured in \(points.count) days"
        }
        guard let lastActivity else { return "Nothing captured yet" }
        let month = DateFormatter()
        month.locale = locale
        month.dateFormat = "LLLL"
        // UTC because `activity`'s keys are UTC calendar days (R-A16); a local
        // time zone would name the wrong month for an activity near midnight.
        month.timeZone = TimeZone(identifier: "UTC")
        return "Nothing new since \(month.string(from: lastActivity))"
    }
}
```
