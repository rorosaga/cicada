# Direction D, part 3a — the Graph page: one quiet floating group, the entity card as a progressive column with the Reader beside it, sources an agent can check (Track DS-3a) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Graph becomes a Direction D canvas page. The canvas fills the content area under the command bar,
and today's four floating islands (find field + observer bar top-left, context legend bottom-left, filter + zoom
bottom-right) collapse into **one quiet floating group** at the bottom-left: the whose-beliefs text tabs, a Legend
button, − + fit and the pan toggle. The Legend opens one panel that is the context legend and the filter popover in
one, with a key to what the shapes mean. The page's own "Find a node" field retires: ⌘K (the command bar) searches
everything, and ⌘F opens find **on the canvas** as an overlay that never pushes it. A node click no longer puts a
modal card over a scrim: the entity card becomes the right-hand **progressive column** (header with the type, the
status and confidence in words, the name, the Summary, Back ⌘[ and Close ×; text tabs Content · Perspectives ·
History · Timeline with counts), its evidence opens the Reader as a further column beside it, and a click on empty
canvas closes it. "Look it up at" says, for each G61 source, which fact it backs up, how it can be read and who added
it — and says nothing it cannot back: no check line and no "Check now" until G61 S3 serves a result. Every graph and
entity-card capability that ships today still works.

**Architecture:** Every decision is a pure function with a table test, and the views render them:
- the bridge's message shapes and call spellings (`GraphMessage.parse`, `GraphJS`);
- the chrome's words, rows and placement (`GraphChrome`, `GraphChromeLayout`);
- what Esc, a click on empty canvas and × close (`GraphDismiss`), and the find field's Esc (`GraphFind`);
- the canvas/column widths (`GraphColumns`);
- the header's words, the tab counts, the source lines, the history link, the timeline rows
  (`EntityHeaderWords`, `EntityTabs`, `FactSourceWords`, `HistoryConversation`, `TimelineKeys`, …).

graph.js gains three bridges — `backgroundClicked` and `escape` posted to Swift, `setSelectedNode` called from Swift
— each tested under the real d3 (`graph-physics-harness.js`) and each proven not to touch the simulation (G109).
The Reader stays the shell's trailing column (`ShellReaderHost`, R-DI6): the Graph does not adopt
`ProgressiveColumns`, because its flexible column is the canvas, not the detail. **No backend change**: no endpoint,
field, ETag or Store domain.

**Tech Stack:** SwiftUI + XCTest (`app/CicadaApp`, macOS 14 floor, built on the macOS 26 SDK), `ImageRenderer` fit
tests; graph.js + d3 v7 in a `WKWebView`, node's built-in test runner over the physics harness.

## Rulings (binding)

Decisions this plan takes where the brief or the rules left a choice, each with its reason, so no task re-opens them.
The ones marked **§9** depart from DESIGN_RULES and get a dated line in its §9 (Task 6).

**Chrome**

- **R-DG1 — §9 — No `cicada.design.focus` flag (DR-73).** R-DS1 / R-DI1's reasons hold unchanged. Comparison is the
  orchestrator's installed build against this branch on the demo bank.
- **R-DG2 — §9 — The floating group and its panels are opaque floating surfaces, not Liquid Glass (DR-14, §10
  Graph).** `LiquidGlass.swift` says glass never goes over the canvas without the G109 frame-time check, and R-SU17
  already let that rule outrank a design doc. Glass samples what is under it every frame; the canvas redraws every
  frame while the simulation runs. `floatingSurface(in:)` is the DR-10 surface: `bgMenu`, the floating ring, one soft
  shadow in light. **Revisit trigger:** an in-app p95 frame time under 16.7 ms on the live bank with glass on.
- **R-DG3 — What the one group holds, and where it goes when the canvas is narrow.** Left to right: the whose-beliefs
  text tabs (only with more than one observer — `hasObserverDiversity`, today's rule), Legend, − + fit, and the pan
  toggle (the mock draws it; the owner asked for it on 2026-09-03). `GraphChromeLayout.group`: at ≥ 640 units of canvas
  the tabs sit in the group (the mock's breakpoint); under that they move to the top of the Legend panel; under 340
  units — the widest group ("Legend · filtered" with its three hues, a spacer and four 28-unit icons, ≈ 303,
  measured) plus its 16-unit inset on each side — the group hides until the canvas widens rather than clip (with the
  tabs it measures ≈ 522, under the 640 breakpoint). At 1× the rail + Reader +
  column at 1200 pt leaves 344 (the group stays); the labelled sidebar + Reader + column at 1200 pt leaves 192 (it
  hides). `GraphChromeTests.testTheWidestGroupFitsItsFloor` renders the group and pins the floor; if it fails, raise
  `groupMinWidth` and this sentence and the §9 line with it. Disclosed, not fixed.
- **R-DG4 — The Legend panel is the context legend, the filter popover and a key, in that order.**
  - Context rows keep **today's** semantics: an empty set is every context, and a click shows *only* the contexts
    clicked (the one-tap "engineering subgraph"), not the mock's hide-one. "Show all" clears.
  - Type rows toggle membership as today, busiest first, with the page count; a type the filter switched off stays
    listed at 0 so it can come back. Hubs and satellites are views, not pages, and do not count.
  - Status uses native checkboxes, minimum confidence a native slider labelled in words ("Any", "50 or more" —
    never "50%"), Show logos a native switch that still calls `pushVisibleLogos()`. Native controls follow the
    Mac's accent by themselves (DR-4); no `.tint`.
  - The key says in words what the canvas draws: bigger is more confident, dashed is fading, an amber ring is a
    waiting question (DR-69's text twin; the amber is `pendingPulse`, graph.js's `PULSE_COLOR` twin).
  - The button reads "Legend", or "Legend · filtered" whenever a filter differs from `GraphFilter()` — the observer
    lens (visible in the tabs) and Show logos (paint, not a filter) do not count.
- **R-DG5 — ⌘F finds on the canvas.** The page publishes ⌘F only while the overlay is closed and the overlay's own
  field publishes while it is open, so one publisher exists at a time (R-SU10). The overlay sits at the canvas's
  top-leading corner, 300 units, a floating surface; it never pushes the canvas (DR-46). Ranking is unchanged
  (`graphVM.searchHits`, `QuickMatch`); rows carry the type dot only (DR-48); ⏎ opens the highlighted node's column
  and closes the overlay; with a query, the last row is "Search all of memory" (⌘K); Esc clears, then closes.
  `GraphSearchField` and the Search affordance on the page are deleted. Opening the find overlay closes the Legend and
  vice versa; leaving the Graph tab closes both.
- **R-DG6 — The Graph's `?` answers for the Graph (DR-69).** `HelpContent.graph` lists ⌘F, ⌘K, Esc's order, ⌘[,
  double-click to focus, Shift or the pan button to pan, and a click on empty space to close — the words for gestures
  the canvas has no other way to explain.

**The column**

- **R-DG7 — §9 — Close means the whole detail; a swap keeps the Reader (DR-28, DR-29).**
  - The column's × and a click on empty canvas close the entity column **and** the Reader when it is open — the mock's
    `closeEntity`, and the Inbox's `closeQuestion`. Pointer paths, on `CicadaMotion.columns`.
  - Esc closes one thing per press, topmost first: the find overlay, the Legend, the Reader, the column (DR-28). A
    keyboard path, inside `Instant.run`.
  - A click on another node swaps the column in place and **keeps** the Reader. This departs from DR-29's
    close-on-swap for the Inbox: here the canonical flow is the Reader's "Show on graph" rows, which exist to swap the
    entity beside the sentence, and a canvas click is the same gesture by pointer. A swap is instant (no width moves).
- **R-DG8 — A click on empty canvas dismisses a floating panel first.** With the find overlay or the Legend open, the
  click only closes them (an outside click on a popover); with none open, it closes the column. A drag is a pan and
  closes nothing; in pan mode every press is a pan.
- **R-DG9 — The canvas keeps the open node in view, by panning only.** `setSelectedNode(id)` records the id, draws a
  neutral ring (the search ring's shape, `PALETTE.nodeStroke`, never the accent — DR-5) and, after every resize,
  pans so the node sits ≥ 80 px inside the canvas. It never changes the zoom scale and never touches `simulation`,
  `alpha`, `alphaTarget` or `restart()` (G109 rule 2's spirit: the transform only). Without it, a node clicked on the
  right half of a 1384 pt canvas vanishes when the column takes 560 of it. **While a G123 reveal is in flight the pan
  waits** (`revealing`) and re-checks when the reveal ends: `revealEntity` selects AND reveals in one update (⌘F's ⏎,
  the Reader's "Show on graph", Sleep and Sources chips), d3 transitions of one name are exclusive, and a keep-in-view
  pan started beside the reveal — or a resize mid-flight, since `zoom.transform` interrupts — would cancel the
  reveal's zoom to the neighbourhood and leave the node parked 80 px from the edge.
- **R-DG10 — Hover stays quiet while the column is open.** The owner's 2026-09-03 rule ("as I move my cursor it still
  highlights the nodes while an entity page is open"); `setHoverSuppressed` is unchanged. Clicks still select.
- **R-DG11 — Esc reaches Swift from the canvas as a message.** The `WKWebView` is usually the first responder, so a
  SwiftUI key handler never hears Esc. graph.js keeps Esc for its ego focus when one is active; otherwise it posts
  `escape` and calls `preventDefault()`, so WebKit never also forwards the key (no double close). The column itself is
  `.focusable()` with `.onExitCommand` for when focus is inside it.
- **R-DG12 — Column widths (`GraphColumns`).** In units (÷ uiScale, DR-70): the column is `clamp(page / 2, 440, 560)`
  alone and `clamp(page / 2, 440, 480)` beside the Reader, never wider than the page; the canvas takes the rest. That
  is the mock at 1440 exactly (560 / 480 rail / 440 labelled), keeps DR-27's 440 floor, and the two always sum to the
  page, so nothing is pushed off-window (DR-31). The Reader's width stays `ColumnLayout.readerWidth` (the shell's).
- **R-DG13 — One card, two styles.** `EntityDetailCard(style: .column | .card)`: the Graph passes `.column` (no card
  chrome, `bgBase`, the column edge, 28-unit insets); Clusters keeps `.card` (`glassCard`) because its page frame is
  DS-3b's. Both get the new header, tabs and sections — one card, one grammar. Clusters' Esc no longer clears the
  Graph's selection (it passes no `onEscape`).

import Foundation

/// Everything graph.js posts, parsed in one place (DS-3a R-DG25). The coordinator used to hand-parse
/// each `type`; a new message is now one case here and one test in `GraphBridgeTests`, and the JS half
/// of every new message is tested under the real d3 (`Tests/graph/graph-canvas-bridge.test.js`).
enum GraphMessage: Equatable {
    case graphReady
    case nodeClicked(String)
    case hubExpanded(String)
    case nodeFocused(String)
    case focusCleared
    /// R-DG8 — a click on empty canvas, never a drag and never in pan mode.
    case backgroundClicked
    /// R-DG11 — Esc with no ego focus: the page decides what it closes.
    case escape
    case jsError(String)

    static func parse(_ body: Any) -> GraphMessage? {
        guard let string = body as? String, let data = string.data(using: .utf8),
              let json = (try? JSONSerialization.jsonObject(with: data)) as? [String: Any],
              let type = json["type"] as? String
        else { return nil }
        let id = json["id"] as? String
        switch type {
        case "graphReady": return .graphReady
        case "backgroundClicked": return .backgroundClicked
        case "escape": return .escape
        case "focusCleared": return .focusCleared
        case "nodeClicked": return id.map(GraphMessage.nodeClicked)
        case "hubExpanded": return id.map(GraphMessage.hubExpanded)
        case "nodeFocused": return id.map(GraphMessage.nodeFocused)
        case "jsError":
            let stack = json["stack"] as? String ?? ""
            let at = "\(json["message"] as? String ?? "?") @ \(json["source"] as? String ?? "?"):"
                + "\(json["line"] as? Int ?? 0):\(json["col"] as? Int ?? 0)"
            return .jsError(stack.isEmpty ? at : "\(at)\n\(stack)")
        default: return nil
        }
    }
}

    case escape

    /// its own tabs and Show logos is paint, so neither counts.
    static func isFiltered(_ filter: GraphFilter) -> Bool {
        let base = GraphFilter()
        return filter.types != base.types || filter.statuses != base.statuses
            || filter.minConfidence > 0 || filter.minDegree != base.minDegree
            || !filter.contexts.isEmpty || !filter.tags.isEmpty

        isFiltered(filter) ? Copy.Graph.legendFiltered : Copy.Graph.legend

    struct TypeRow: Equatable, Identifiable {
        let type: EntityType
        let count: Int
        let isOn: Bool

/// R-DG12 — the canvas and the entity column. The canvas is the flexible column (the list's role in §5.3), so
/// the Graph does not reuse `ColumnLayout`, whose flexible column is the detail. Widths are units (÷ uiScale,
/// DR-70), and the two always sum to the page, so nothing is ever pushed off-window (DR-31).
enum GraphColumns {
    /// DR-27's floor for the detail column.
    static let entityMin: CGFloat = 440
    /// The approved mock: 560 with nothing beside it, 480 beside the Reader (440 once the page is narrower).
    static let entityMax: CGFloat = 560
    static let entityMaxBesideReader: CGFloat = 480

    struct Plan: Equatable {
        var canvas: CGFloat
        var entity: CGFloat
    }

    static func plan(pageWidth: CGFloat, scale: CGFloat, entityOpen: Bool, readerOpen: Bool) -> Plan {
        let page = max(pageWidth, 0)
        guard entityOpen else { return Plan(canvas: page, entity: 0) }
        let s = max(scale, 0.1)
        let units = page / s
        let ceiling = readerOpen ? entityMaxBesideReader : entityMax
        let entityUnits = min(min(max(units / 2, entityMin), ceiling), units)
        let entity = min((entityUnits * s).rounded(), page)
        return Plan(canvas: page - entity, entity: entity)
    }
}

    static func date(_ iso: String?) -> Date? {
        guard let iso, !iso.isEmpty else { return nil }
        let full = ISO8601DateFormatter()
        full.formatOptions = [.withInternetDateTime]
        let fractional = ISO8601DateFormatter()
        fractional.formatOptions = [.withInternetDateTime, .withFractionalSeconds]
        let dayOnly = DateFormatter()
        dayOnly.dateFormat = "yyyy-MM-dd"
        dayOnly.timeZone = TimeZone(identifier: "UTC")
        return full.date(from: iso) ?? fractional.date(from: iso) ?? dayOnly.date(from: String(iso.prefix(10)))
    }

    static func days(since iso: String?, now: Date) -> Int? {

/// R-DG18 — one G61 source in words. The voices mirror `fact_sources.voiced_hint`, so the card and a conflict's

enum FactSourceWords {
    struct Line: Equatable {
        let ref: String
        let isLink: Bool
        let forFact: String
        let readBy: String?
        let addedBy: String
        /// The app whose mark stands beside `addedBy` (DR-52).
        let addedByOrigin: String?
        let note: String?
        /// The ref in full (a long one is truncated on screen) and, for an agent, its raw id (DR-54).
        let help: String
    }

    static func line(_ s: EntitySource, locale: Locale = .autoupdatingCurrent) -> Line {
        let who = addedBy(s.addedBy)
        let words = EntityDates.shortDay(s.addedAt, locale: locale).map { "\(who.words) · \($0)" } ?? who.words
        let rawShown = who.origin != nil || who.words != Copy.Graph.foundByAnAgent
        return Line(ref: s.ref, isLink: s.url != nil, forFact: forFact(s.predicate),
                    readBy: readBy(access: s.access, kind: s.kind), addedBy: words, addedByOrigin: who.origin,
                    note: note(accepted: s.accepted, onlyMe: s.onlyMe),
                    help: rawShown ? s.ref : "\(s.ref)\n\(Copy.Graph.addedByRaw(s.addedBy))")
    }

    static func forFact(_ predicate: String?) -> String {
        let p = (predicate ?? "").trimmingCharacters(in: .whitespaces)
        guard !p.isEmpty else { return Copy.Graph.forAnyFact }
        return Copy.Graph.forFact(p.replacingOccurrences(of: "-", with: " ").replacingOccurrences(of: "_", with: " "))
    }

    /// The stated access wins (a stated `unknown` says nothing); unstated, only the kind can speak.
    static func readBy(access: String?, kind: String) -> String? {
        if let stated = access?.trimmingCharacters(in: .whitespaces).lowercased(), !stated.isEmpty {
            switch stated {
            case "public": return Copy.Graph.publicPage
            case "signed_in": return Copy.Graph.needsSignIn
            case "local": return Copy.Graph.fileOnThisMac
            default: return nil
            }
        }
        switch kind {
        case "path", "repo": return Copy.Graph.fileOnThisMac
        case "app": return Copy.Graph.anApp
        default: return nil
        }
    }

    static func addedBy(_ raw: String) -> (words: String, origin: String?) {
        let who = raw.trimmingCharacters(in: .whitespaces)
        if who.isEmpty || who == "user" { return (Copy.Graph.addedByYou, nil) }
        if who == ContributorIdentity.systemAuthor { return (Copy.Graph.foundByCicada, nil) }
        if who != "unknown", OriginIconography.logoName(for: who) != nil || OriginIconography.appBundleId(for: who) != nil {
            return (Copy.Graph.addedBy(OriginIconography.label(for: who)), who)
        }
        return (Copy.Graph.foundByAnAgent, nil)
    }

    static func note(accepted: Bool?, onlyMe: Bool?) -> String? {
        if onlyMe == true { return Copy.Graph.onlyYouKnow }
        if accepted == true { return Copy.Graph.youChoseThis }
        return nil
    }

        return (InboxAge.compact(days: days), help)
    }

/// R-DG23 — the Timeline tab's rows.
enum TimelineKeys {
    static func rows(claims: [Claim], requested: BeliefKey?) -> [BeliefKey] {
        let contested = EntityTabs.contested(claims)
        guard let requested, !contested.contains(requested) else { return contested }
        return [requested] + contested
    }

    static func summary(_ key: BeliefKey, claims: [Claim], locale: Locale = .autoupdatingCurrent) -> String {
        let group = claims.filter { BeliefKey($0) == key }
        let first = group.map(\.validFrom).filter { !$0.isEmpty }.min()
        return Copy.Graph.beliefsSince(group.count, EntityDates.shortDay(first, locale: locale))
    }

    static func heading(contested: Int) -> String { contested > 0 ? Copy.Graph.contestedBeliefs : Copy.Graph.thisBelief }
}

/// R-DG24 — where "Show in conversation" goes.
enum HistoryConversation {
    enum Action: Equatable {
        case none
        case open(episode: String)
        case choose
    }

    static func action(sessions: [String], openEpisode: [String: String]) -> Action {
        guard !sessions.isEmpty else { return .none }
        let episodes = sessions.compactMap { openEpisode[$0] }
        if episodes.count == sessions.count, let first = episodes.first, Set(episodes).count == 1 {
            return .open(episode: first)
        }
        return .choose
    }
}

/// §3b — who believes what: current beliefs grouped by observer, Cicada, then the person, then outside sources.
enum PerspectiveGroups {
    struct Group: Identifiable {
        let observer: Observer
        let claims: [Claim]
        var id: String { observer.id }
    }

    struct Divergence: Identifiable, Equatable {
        let key: BeliefKey
        /// "Cicada: sqlite-vec · You: csv-storage"
        let line: String
        var id: String { key.id }
    }

    static func rank(_ observer: Observer) -> Int {
        switch observer {
        case .agent: 0
        case .rodrigo: 1
        case .external: 2
        }
    }

    static func of(_ claims: [Claim]) -> [Group] {
        Dictionary(grouping: claims.filter(\.isValid), by: \.observer)
            .map { Group(observer: $0.key, claims: $0.value) }
            .sorted { rank($0.observer) != rank($1.observer) ? rank($0.observer) < rank($1.observer)
                                                             : $0.observer.label < $1.observer.label }
    }

    static func heading(_ group: Group) -> String { "\(group.observer.label) · \(UsageFormat.count(group.claims.count))" }

    /// Keys where two or more observers hold different current values.
    static func divergences(_ claims: [Claim]) -> [Divergence] {
        Dictionary(grouping: claims.filter(\.isValid), by: { BeliefKey($0) })
            .compactMap { key, group -> Divergence? in
                guard Set(group.map(\.observer)).count >= 2, Set(group.map(\.object)).count >= 2 else { return nil }
                let ordered = group.sorted { rank($0.observer) < rank($1.observer) }
                return Divergence(key: key, line: ordered.map { "\($0.observer.label): \($0.object)" }.joined(separator: " · "))
            }
            .sorted { $0.id < $1.id }
    }
}
