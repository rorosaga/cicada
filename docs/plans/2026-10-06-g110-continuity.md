# G110 — automatic project continuity, slices 1–2 (plan)

Spec (binding): [`docs/specs/2026-10-06-project-continuity.md`](../specs/2026-10-06-project-continuity.md).
Backlog: [G110](../goals/memory-evolution.md#g110), with G48 (lineage), G104 (revision safety), G105 (capture),
G149 (startup delivery), G53/G75 (the bounded entry point). Branch `feat/g110-continuity`, based on `dev` a6b72f1c.

**Goal of these two slices.** After the hooks Cicada already installs, a fresh Claude Code or Codex session opened in
the same folder — because the last one is full, was cleared, closed or crashed — starts with a short, cited note saying
where the work there stopped, *before Sleep has run*, and can pull more through one governed read. No recap, no save
tool, no LLM at capture. Cursor/Grok/remote (slices 3–4) and the CLI (slice 5) are out of scope; the design below is
what they will reuse.

---

## Global Constraints

1. **No LLM anywhere on these paths.** Capture stays file I/O; the projection is string work over episode files.
2. **Transcripts are read only by `transcript_capture.capture_transcript`** (G105 R2). Nothing new opens a transcript;
   the fork-prefix check (T3) compares *bodies already in the bank*.
3. **The backend never opens or runs git in a person's folder.** The *hooks* (children of the harness, the authorized
   observer) read `.git/HEAD` and ref files as bytes — never `git`, never a working file. The MCP stdio process may do
   the same (it is the harness's child too, like `cicada_repo_context`).
4. **The ≤ 1,800-token handshake holds** for everything SessionStart injects (header + primer + continuity block; the
   G166 reading sentence keeps riding beside it as today). **R12 holds**: every `cicada_x(args)` the block or the contract
   names is in the tool schema.
5. **Memory is data, never a command.** The person's quoted words are labeled as history; the note says to verify the
   workspace before editing and to act only on what the person asks now.
6. **One episode per session (G104) and no double consolidation.** A new session keeps its own harness id; nothing
   copies a source session id onto it. A fork's copied prefix is not captured twice.
7. **No Sleep stage changes in these slices.** Lineage is *recorded* (frontmatter), not yet *used* by Sleep (see Open
   follow-ups).
8. **Nothing personal in this plan, tests or commits.** Fixtures: `alpha-project`, `bob-example`, `example.com`,
   `/home/example/...` paths.
9. **Provider-neutral copy** in every string the note and the tool print (no provider or model named as the doer).
10. **Ids, enums and times only** outside a bank (the new session registry, ledger fields). Never a path, a title or a
    prompt there.
11. Never auto-stash, reset or transfer a working tree; the note only tells the agent to *inspect*.

## Rulings

**C1 — The working-context projection is assembled on demand, from captured episodes, at the moment it is read.**
Compared (evidence opened for each):

- *A typed episode* (a "checkpoint" episode per session). Rejected: an episode is captured raw experience, enters the
  Sleep queue (`processed: false`) and git, so Sleep would consolidate the projection as new evidence — the echo the
  spec forbids — and it duplicates the session's own body (a transcript copy by another name). It also needs a writer
  at Stop time that decides what a "decision" is, which without an LLM it cannot.
- *A derived per-project file outside git* (like the FTS/vector indexes). Workable and disposable, but it is a second
  copy of the session tail that must be invalidated on every Stop, every Sleep retirement and every bank switch, and it
  buys nothing: the measured cost of reading the source directly is small (below).
- *On-demand assembly* — **chosen.** `api/services/continuity.py` reads the bank's episode files (stat + a 2 KB head
  read to prefilter, a full `markdown_parser.parse` only for the ≤ 6 candidate sessions) and the new ids-only session
  registry (C4), and renders either the startup block or the full `cicada_continue` text. Nothing is stored; every
  field carries its revision/source reference (episode id, `content_hash`, session id, `captured_at`, the turn
  sidecar's times). It is "rebuildable" in the strongest sense: it is never built. It does not touch `_state.md`
  (`storage.md`: a cursor, never a copy).
  *Why not `bank_index`:* it is process-local and cold after a backend restart; a cold parse of every episode is 1–3 s
  (`bank_index.py:1-6`) against SessionStart's 800 ms (`hook_recall.PRIMER_BUDGET_S`). The raw head prefilter is one
  `scandir` + ≤ 600 small reads, with a latency test (T5).
  *What it can say before Sleep* is exactly what capture kept (G105: the person's turns and the agent's final reply per
  turn, code stripped) plus attributed agent writes stamped with the session (MCP episodes and claims carrying its
  `session_id`). "Decisions, rejected approaches, blockers, next action" are therefore recovered as **the person's own
  requests in that session (an outline) and the last turns verbatim**, which is where a working agent states them; the
  consolidated graph adds claims once Sleep runs. The note never claims more.

**C2 — Identity: project = the folder the harness reports; task = one session lineage in it; the bank = the capture
bank.**
- The hook's own `cwd` (both harnesses send it: `api/hooks/recall.py:159`, `api/hooks/capture.py:143`) is the only
  workspace signal. It is used in memory for matching and never logged or written outside the episode's existing
  `project_dir` (`transcript_capture.py:365-366`). `HookContextRequest.cwd` is currently "accepted and unused"
  (`api/routers/capture.py:225-238`, R-H17); this plan starts using it, under the same never-logged rule.
- **Workspace key** = the cwd as a string with a trailing `/.worktrees/<name>` or `/.claude/worktrees/<name>` segment
  folded to its parent, trailing `/` stripped. Two folders are *related* when one key equals or is a path-prefix of the
  other. String work only — no `resolve()`, no `stat` of the person's folder.
- **Project** = the project page whose declared `repos:` path (from `_state.md`'s project rows, already read by the
  primer, or the page itself when `cicada_continue(project=…)` names it) is a path-prefix of the workspace key; else the
  folder itself (no page is ever created).
- **Task** = a session in that workspace. Same exact cwd (same worktree) ⇒ same task. Sessions in *different* folders of
  one workspace active within 24 h of each other ⇒ **ambiguous**: the note lists ≤ 3 and tells the agent to ask the
  person one question unless their first message says which (the spec's focused selection question).
- **Session lineage.** A new destination session keeps the id its harness minted (`/clear`, a fresh start and a fork
  all mint one; verified in both harnesses' SessionStart `source` enum, Ruling C5). Cicada records an **observed**
  relation, never a declared one: "Cicada delivered episodes X, Y to session S at T" (registry, C4), stamped onto S's own
  episode as `continues: [X, Y]` at its first capture. This answers G110(iv) — a lineage self-reported by a third-party
  tool would be an unauthenticated provenance channel; this one is Cicada's own act.
- **No double consolidation.** (a) A `/clear`ed or freshly started session's transcript does not contain the source's
  turns, so capturing it adds only new turns. (b) The injected note opens with `recall_text.INJECTION_PREFIX` and is
  dropped by the extractor in every shape (`transcript_extract.py:66-81` tags and `_HOOK_OUTPUT_RE`, `:327`, `:418`); T6 adds a test with the continuity
  block itself. (c) A **fork** (`source: fork`) copies the parent's history into the new transcript; T3 strips the
  longest prefix of the new body that equals a captured parent body of the same harness and workspace, at a turn
  boundary, only when the registry says the session started as a fork — and stamps `forked_from: {episode, turns}`;
  later Stops strip the same `turns` again (deterministic). (d) An agent's paraphrase of the delivered note is captured
  as *agent* words in the new session; lineage is recorded so G104 can discount it (Open follow-up 2). `--resume`
  without a fork keeps the session id and the one episode (G104's existing path).

**C3 — Delivery: SessionStart on `startup` and `clear` only, inside the 1,800-token budget; more through
`cicada_continue`.**
- `resume`, `compact` and `fork` already carry their own history (the resumed transcript, the compaction summary, the
  copied prefix), so re-injecting it would be noise; only `startup`, `clear` and a missing `source` (an older harness)
  get the block.
- The block appends to the primer under the existing "From Cicada" header (so it is never captured back and contract
  item 8 already explains it). Three renderings by budget: **full** ≤ 450 tokens, **compact** ≤ 200, **pointer**
  ≤ 60. The primer is built for SessionStart with a 300-token **reserve** whenever a block exists
  (`handshake.load_or_build(…, reserve=300)` → `_fit` aims at `MAX_TOKENS - reserve`; the reserve is part of the cache
  key and file name). The largest rendering that keeps header + primer + block ≤ 1,800 wins; if none fits the block is
  dropped (`continuity: no_room` in the ledger). Measured on a6b72f1c: the fixed primer is 1,121 tokens with no state
  and 1,564 with seven full project rows, so the pointer always fits and the full block usually does.
- **Freshness and incomplete flags are explicit lines**, never implied: the last captured turn's time and how long
  before this session; "not yet consolidated" while `processed: false`; a *later prompt not captured* when the
  registry's `last_prompt_at` for the source is after its last captured turn (a crash, an interrupt, a quota stop —
  the spec's "incomplete latest turn"); a *last request with no captured reply* when the body ends on a person's turn
  (a SessionEnd/PreCompact flush mid-turn); a *capture cap* line when the head-stable session cap dropped later turns
  (T3 records how many and until when); "that session may still be open" when it has no `ended_at` and was active in
  the last 10 minutes.
- **Workspace freshness:** the hooks report `{branch, head}` read from `.git` files (C2/C6); the block says "then:
  `feat/x` @ `1a2b3c4`; now: `feat/y` @ `5d6e7f8` — changed since: inspect before editing", or "same branch and commit;
  uncommitted changes are not known to Cicada — check `git status`".
- **`cicada_continue(project?, path?)`** (stdio only; `NEVER_REMOTE` until slice 4 decides its scope) returns the full
  projection: the chosen session's identity and lineage, the person's requests in it as a dated outline (≤ 40 × 160
  chars), the last 6 turns (≤ 1,200 chars for the person, ≤ 2,000 for the agent), what agents recorded under that
  session, workspace then/now, the gaps, other recent sessions, and the verify-first line. Contract item 1 names it
  (`CONTRACT_VERSION` 14), so a client with no hooks (Cursor today) still has the labeled fallback.

**C4 — One small registry outside every bank: `$CICADA_HOME/continuity/<bank-slug>.json`.** Rows keyed
`<harness>:<session_id>`: `source` (enum), `started_at`, `last_prompt_at`, `ended_at`, `delivered` (≤ 5 episode ids).
Written by the hook-context route (start, delivered, every prompt) and the capture route (`SessionEnd`). Ids, enums
and times only — no cwd, no title, no prompt. 30-day expiry applied in memory, ≤ 1,000 rows, `fcntl.flock` +
`os.replace` (the `reading_asks.py:189-227` pattern), `bank_slug` reused from `reading_asks.py:61`. It is needed because
SessionStart happens before the session has an episode, and because a prompt that never reached a Stop leaves no trace
in the bank — the registry is how the next session learns a turn is missing. A failure to write it never costs a
prompt (swallowed, `continuity: registry_error` enum in the ledger).

**C5 — Harness hooks, verified (Context7, 2026-10-06), and the flush we add.**

| Event | Claude Code (code.claude.com/docs/en/hooks) | Codex (`codex-rs/hooks/src/schema.rs`, `events/session_start.rs`) | Used for |
|---|---|---|---|
| `SessionStart` | `source`: `startup\|resume\|clear\|compact\|fork`; `model?` | same five `source` values | delivery (C3), registry start |
| `UserPromptSubmit` | `prompt` | `prompt`, `turn_id`, `agent_id?` | registry `last_prompt_at` |
| `Stop` | after each reply | after each reply | capture (today) |
| `PreCompact` | `trigger` manual/auto | present in `HookEventsToml` | **new flush**: capture before compaction |
| `PostCompact` | carries `compact_summary` (model prose) | present | **not used**: content, not a pointer — G76's content-free ruling stands; capturing model prose as memory needs its own ruling |
| `SessionEnd` | `reason` (`clear`, exit, …); short budget | `reason: other`, `transcript_path` nullable | **new flush** + registry `ended_at` |

- The capture hook (one command, `api/hooks/capture.py`) is registered under `Stop`, `PreCompact` and `SessionEnd`
  (`CAPTURE_EVENTS`). The endpoint is already idempotent by content hash, so extra firings cost nothing. `SessionEnd`
  may be cut off by its short budget — best effort; `Stop` stays primary.
- **What is lossless and what is not:** a turn the agent finished is captured by its `Stop`. A crash, kill or quota stop
  mid-turn loses that turn's reply and possibly the prompt; the registry's `last_prompt_at` makes that loss *visible*
  in the next session. The note never claims lossless recovery.
- Claude Code's fork does not expose the parent session id to hooks (no such field in `SessionStartHookInput`); C2(c)
  therefore matches content, gated on `source: fork`.
- Codex runs a new hook only after the person trusts it (already documented, `mcp.md` "When it is skipped").

**C6 — Workspace observation is two stdlib copies plus one service copy, pinned by a parity test.** The hooks import
nothing from `api.*` by rule (`api/hooks/capture.py:23-25`); `api/hooks/capture.py` and `api/hooks/recall.py` each get
`_workspace(cwd)` (walk ≤ 8 parents for `.git`, follow a worktree's `gitdir:` and `commondir`, read `HEAD`, resolve a
branch through the loose ref or `packed-refs`, ≤ 4 KB per file, ≤ 20,000 `packed-refs` lines), and
`api/services/git_head.py` holds the same function for the MCP process. One test runs all three against the same
synthetic `.git` trees.

**C7 — Capture gaps are recorded, the cap is not changed here.** The head-stable 100,000-character session cap
(`transcript_extract.py:58-61`) means a long session — the primary "context is full" case — can lose its *latest*
turns, exactly what continuity needs. Changing retention is G104's decision (its row names this). This plan records
the gap on the episode (`capture_gap: {dropped_turns, last_turn_at}`, outside `content_hash`) and every note discloses
it. Open risk 1.

### T1 — the session registry (C4)

**Files:** `api/services/continuity_sessions.py`, `api/tests/test_continuity_sessions.py`.

**Interface:**

```python

EXPIRES_AFTER_DAYS = 30
MAX_ROWS = 1000
MAX_DELIVERED = 5

def path_for(memory_path: Path) -> Path            # cicada_home()/"continuity"/f"{reading_asks.bank_slug(memory_path)}.json"

def prompted(memory_path, *, harness, session_id, now=None) -> None
def ended(memory_path, *, harness, session_id, now=None) -> None
def get(memory_path, harness, session_id, *, now=None) -> dict | None
def all_rows(memory_path, *, now=None) -> dict[str, dict]
```

Row: `{"source": str|None, "started_at": iso|None, "last_prompt_at": iso|None, "ended_at": iso|None,
"delivered": [episode ids]}`. `harness ∈ transcript_extract.HARNESSES`; `session_id` must match
`transcript_capture._SESSION_ID_RE`; a delivered id must match `episode_ids.EPISODE_ID_RE`; `source` not in `SOURCES`
→ `None`. Anything invalid is dropped silently (never raises). `started` on an existing row keeps `started_at` and
replaces `source`/`delivered` only when given. Writes: read-modify-write under `fcntl.flock` on
`<file>.lock`, temp file + `os.replace`, mode 0600, parent 0700; rows past `MAX_ROWS` drop oldest by
`max(started_at, last_prompt_at, ended_at)`; expiry in memory on every read and persisted on the next write.

**Tests:** round trip of all three writers; invalid harness/session/episode ids and a path-like value never reach the
file; expiry after 30 days (pinned `now`); the 1,001st row evicts the oldest; two banks get two files; a corrupt file
reads as empty and the next write replaces it; the file holds no key outside the row schema (privacy guard: write rows
with a cwd-looking `source` and assert no `/` in the file).

**Commit:** `feat(continuity): an ids-only session registry outside every bank (G110)`

### T2 — the hooks observe the workspace and forward `source` (C5, C6)

**Files:** `api/services/git_head.py`, `api/hooks/capture.py`, `api/hooks/recall.py`, `api/routers/capture.py`,
`api/tests/test_git_head.py`, `api/tests/test_capture_hook.py`, `api/tests/test_recall_hook.py`,
`api/tests/test_hook_context_route.py`.

**Interface (identical body in all three places; the hooks' copies are named `_workspace`):**

```python
_SHA = re.compile(r"[0-9a-f]{40}(?:[0-9a-f]{24})?")
MAX_PARENTS = 8
MAX_FILE_BYTES = 4096
MAX_PACKED_LINES = 20_000

def read_head(cwd: str | None) -> dict | None:
    """{"branch": str | None, "head": str | None} for the checkout `cwd` is in, read from .git files.
    Never runs git, never reads a working file; None when there is no checkout or anything fails."""
    try:
        if not cwd:
            return None
        here = Path(cwd)
        gitdir = None
        for _ in range(MAX_PARENTS):
            dotgit = here / ".git"
            if dotgit.is_dir():
                gitdir = dotgit
                break
            if dotgit.is_file():
                text = _small(dotgit)
                if not text.startswith("gitdir:"):
                    return None
                target = Path(text[len("gitdir:"):].strip())
                gitdir = target if target.is_absolute() else here / target
                break
            if here.parent == here:
                return None
            here = here.parent
        if gitdir is None:
            return None
        common = gitdir
        if (gitdir / "commondir").is_file():
            rel = Path(_small(gitdir / "commondir").strip())
            common = rel if rel.is_absolute() else gitdir / rel
        head = _small(gitdir / "HEAD").strip()
        if head.startswith("ref: "):
            ref = head[5:].strip()
            branch = ref[len("refs/heads/"):] if ref.startswith("refs/heads/") else ref
            return {"branch": branch[:200] or None, "head": _ref_sha(gitdir, common, ref)}
        return {"branch": None, "head": head if _SHA.fullmatch(head) else None}
    except (OSError, ValueError, UnicodeDecodeError):
        return None

def _small(path: Path) -> str:
    with open(path, "rb") as fh:
        return fh.read(MAX_FILE_BYTES).decode("utf-8")

def _ref_sha(gitdir: Path, common: Path, ref: str) -> str | None:
    if ".." in ref.split("/"):
        return None
    for base in (gitdir, common):
        loose = base / ref
        if loose.is_file():
            sha = _small(loose).strip()
            return sha if _SHA.fullmatch(sha) else None
    packed = common / "packed-refs"
    if packed.is_file():
        with open(packed, encoding="utf-8", errors="replace") as fh:
            for n, line in enumerate(fh):
                if n >= MAX_PACKED_LINES:
                    break
                parts = line.strip().split(" ")
                if len(parts) == 2 and parts[1] == ref and _SHA.fullmatch(parts[0]):
                    return parts[0]
    return None
```

- `api/hooks/capture.py:139-145`: add `"workspace": _workspace(payload.get("cwd"))` to `fields` (only when not `None`).
- `api/hooks/recall.py:156-163`: add `"source": payload.get("source") if event == "session_start" and isinstance(...,
  str) else None` and, for `session_start` only, `"workspace": _workspace(payload.get("cwd"))`.
- `api/routers/capture.py`: a shared model

  ```python
  class WorkspaceObservation(BaseModel):
      branch: str | None = Field(None, max_length=200, pattern=r"^[^\x00-\x1f]+$")
      head: str | None = Field(None, pattern=r"^[0-9a-f]{40}([0-9a-f]{24})?$")
  ```

  `TranscriptCaptureRequest.workspace: WorkspaceObservation | None = None`;
  `HookContextRequest.source: Literal["startup", "resume", "clear", "compact", "fork"] | None = None` (an unknown
  value from a newer harness must not 422 the hook: declare it `str | None` with `max_length=16` and map unknown → `None`

### T3 — capture records gaps, workspace, lineage and strips a fork's prefix (C2, C7)

**Files:** `api/services/transcript_extract.py`, `api/services/transcript_capture.py`, `api/routers/capture.py`,
`api/tests/test_transcript_extract.py`, `api/tests/test_capture_continuity.py` (new).

- `_Builder` (`transcript_extract.py:155-251`): new fields `cap_dropped_turns = 0`, `last_seen_at: str | None`. In
  `_add`, before the cap check, `if ts: self.last_seen_at = ts`; in the cap branch `self.cap_dropped_turns += 1`.
  `finish` adds `"cap_dropped_turns"` to `summary` and `last_seen_at` to `Conversation` (new field, default `None`).
- `capture_transcript(…, workspace: dict | None = None, hook_event: str | None = None)`:
  - after a successful write or `unchanged`: `if hook_event == "SessionEnd": continuity_sessions.ended(…)`
    (swallowing `OSError`), so a `/clear` or exit marks the source as ended.
  - frontmatter helpers, all outside `content_hash` and placed before `turns` (which stays last, R-PB4):
    - `workspace: {branch, head}` when given (replaced whole on every write);
    - `capture_gap: {dropped_turns: n, last_turn_at: <iso>}` when `summary["cap_dropped_turns"] > 0`, removed otherwise;
    - `continues: [episode ids]` from `continuity_sessions.get(memory_path, harness, session_id)["delivered"]` when the
      row has any and the key is absent (never overwritten once set).
  - **Fork prefix** (new episode only, and only when the registry row's `source == "fork"`):
    `_fork_parent(episodes_dir, harness, project_dir, body, conv)` scans `ep_*.md` newest-mtime first (≤ 200 files,
    raw-text prefilter `capture_kind: transcript` and `harness: <harness>` in the first 2 KB), parses candidates whose
    `project_dir` is related (C2, `continuity.related`) and whose `session_id` differs, and returns `(parent_id, k)` for
    the largest `k ≥ 2` such that the parent body starts with the child's first `k` turns rendered by `_body`, at a
    turn boundary (`len(parent) == cut or parent[cut] == "\n"`), with at least one `assistant` turn among them. The
    child keeps `conv.turns[k:]`; `forked_from: {episode: parent_id, turns: k}` is written; when

## Open risks and follow-ups (for the orchestrator)

1. **The capture cap hits exactly the case continuity exists for.** A session long enough to fill a context can pass
   100,000 kept characters, and the cap is head-stable, so its *latest* turns are the ones not in memory. This plan
   discloses it in every note (`capture_gap`), but continuity on long sessions stays weak until G104 decides retention
   (e.g. a head + tail body). Measure on the live bank how many Stop-hook episodes carry `session_cap_hit` before
   accepting slice 1 on real sessions.
2. **Echo through the agent's own words.** The note is never captured, but a receiving agent that restates it is
   captured as agent evidence in the new session; Sleep may count it as support or a second mention. Lineage
   (`continues`, `forked_from`) is now on the episode for G104 to discount (count a lineage chain as one promotion
   unit; dedup support across a chain). Not done here: no Sleep stage changes.
3. **Unverified harness behaviour, to check live (not by a build agent — it needs `~/.claude`):** that a Claude Code
   fork's transcript copies the parent's turns verbatim (the strip only fires on an exact prefix, so a mismatch
   degrades to today's behaviour); that `SessionEnd` capture completes within its budget; that Codex sends `source`
   and `cwd` at SessionStart and runs `PreCompact`/`SessionEnd` from `hooks.json`.
4. **Existing installs read `stale`** for auto-save after T4 until the person accepts the two new steps (or re-runs
   `install.sh`); the app already offers the steps for `stale`.
5. **A long-lived MCP process after `/clear`** keeps the previous session id (`mcp/server.py:82-125`), so MCP writes in
   the new session are attributed to the old one. Not caused by this plan; recorded for G48.
6. **Branch names enter the bank** (episode `workspace:`). They are the person's own metadata in their private bank, but
   they are new there; never logged, never in the registry or the ledger.
