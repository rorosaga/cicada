**Runs on** Apple silicon Macs (M1 or later) with macOS 14 Sonoma or later.

**Install** in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/rorosaga/cicada/main/scripts/install-release.sh | bash
```

Or download `Cicada-macos-arm64.zip` below, unzip it and move Cicada to Applications. Cicada is not notarized yet, so
the first time you open a browser download macOS refuses it: open **System Settings → Privacy & Security** and click
**Open Anyway** next to Cicada. The Terminal install doesn't need this step. Installed copies update themselves.
